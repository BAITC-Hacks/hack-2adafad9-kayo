Прогноз выработки ВЭС

загрузка данных…

Нет данных прогноза. Ожидается файл web/data.json рядом со страницей.

Если страница открыта двойным кликом, браузер может не пустить её к файлу. Тогда либо положите рядом data.js (его делает make_data_js.py), либо запустите python -m http.server в папке web.

Агент считает почасовую выработку двух турбин ВЭС на 24–48 часов вперёд по прогнозу погоды и объясняет результат простым языком — без ручной калибровки.

Качество прогноза

Доли от установленной мощности. Скилл — насколько ошибка меньше, чем у персистентности: 0 — как у неё, 1 — идеальный прогноз.
